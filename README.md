# Saarah Adnan Portfolio

A polished, single-page recruiter portfolio for Saarah Adnan, a Toronto-based
Junior Accountant and Honours Bachelor of Commerce in Accounting graduate.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm test
```

The site is built with Next.js, React, TypeScript, Tailwind CSS, and vinext for
Cloudflare-compatible Sites deployment. It is intentionally static and uses no
database, authentication, analytics, or contact-form backend.
